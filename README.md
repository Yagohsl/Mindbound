## 🕰️ Histórico do Projeto (Protótipo em Pygame)

Antes da transição definitiva para a Godot Engine, o conceito inicial deste TCC foi prototipado do zero em Python utilizando a biblioteca Pygame. Essa versão inicial foi fundamental para validar a física de colisão, hitboxes, Máquinas de Estados Finitas (FSM) e o sistema de diálogos psicoeducativos.
